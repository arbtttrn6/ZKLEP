# ZKLEP
Звукоген (Текст-в-речь / Text-to-speech), створяющий звукофайл путем склейки 
звукофайлов букв  
arbtttrn6, 2026.  
  
== RU ==  
Рядом с программой:  
1) создать папку "output";  
2) создать папку "sounds";  
  2.1) в папке "sounds" создать папку "bank1" (и сколько угодно других);  
  2.2) в папках внутри "sounds" добавлять звуковые файлы для различных букв,  
     которые называются также как и сами звуки латиницей.  
       Например:  
         a.wav, b.wav, sz.wav, cz.wav, ...  
  
  
== ISV ==  
Pored programy:  
1) stvoriti direktoriju "output";  
2) stvoriti direktoriju "sounds";  
  2.1) v direktorije "sounds" stvoriti direktoriju "bank1" (i koliko želano drugyh);  
  2.2) v direktorije vnutri "sounds" dodavati zvukove fajly za različne litery,  
    ktore imajut imena podobne i takove kako i zvuky, latiniceju.  
      Naprimer-napriklad:  
        a.wav, b.wav, sz.wav, cz.wav, ...
